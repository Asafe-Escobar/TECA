# TECA SBC

Landing page do Treinamento em Emergências Cardiovasculares TECA SBC.

Site estático em HTML, CSS e JavaScript. Inclui fotos, fontes e versões dos vídeos de fundo para desktop e celular.

## Executar localmente

```sh
python -m http.server 8080
```

Acesse http://localhost:8080.

## Publicar

Use a raiz deste repositório como diretório de publicação. Não é necessário instalar dependências nem executar build.
